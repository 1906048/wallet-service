🚀 HOW TO RUN THE APPLICATION

Option 1: Docker Compose (RECOMMENDED)
────────────────────────────────────────
Make sure Docker Desktop is running, then:

  cd /Users/administrator/Downloads/P2PTransfer
  docker compose up --build

Result:
  - PostgreSQL starts on localhost:5432
  - Spring Boot app starts on localhost:8080
  - Database migrations run automatically (Flyway)
  - Logs stream to console + /tmp/wallet-service.log

Test the app:
  curl -s http://localhost:8080/actuator/health


Option 2: Maven Spring Boot Plugin
───────────────────────────────────
Requires PostgreSQL running locally on localhost:5432 with:
  - Database: wallet
  - User: wallet
  - Password: wallet

  cd /Users/administrator/Downloads/P2PTransfer
  mvn spring-boot:run

Result:
  - App starts on localhost:8080
  - Connects to local PostgreSQL


Option 3: Direct Java (after building with Maven)
──────────────────────────────────────────────────
  cd /Users/administrator/Downloads/P2PTransfer
  java -jar target/wallet-service-1.0.0.jar \
    --spring.datasource.url=jdbc:postgresql://localhost:5432/wallet \
    --spring.datasource.username=wallet \
    --spring.datasource.password=wallet
